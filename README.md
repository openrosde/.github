# .github

This repository holds the organization profile of OpenRoSDE and the default community health files of every repository of [https://github.com/openrosde](https://github.com/openrosde).
A repository that holds a file of the same name, such as its own `CONTRIBUTING.md`, uses that file instead.

## 📁 Contents

| Path                               | Contents                                                                          |
| ---------------------------------- | --------------------------------------------------------------------------------- |
| `profile/README.md`                | Profile shown on [https://github.com/openrosde](https://github.com/openrosde)     |
| `CODE_OF_CONDUCT.md`               | Code of conduct, adapted from the Contributor Covenant 2.1                        |
| `CONTRIBUTING.md`                  | Default contributing guide, which points to the guide of each repository          |
| `SECURITY.md`                      | Security policy: how to report a vulnerability privately                          |
| `SUPPORT.md`                       | Where to find help                                                                |
| `.github/ISSUE_TEMPLATE/`          | Default issue forms for bug reports and feature requests, and their contact links |
| `.github/pull_request_template.md` | Default pull request description: Summary, Changes, Testing, Related, Changelog   |
