# Support

## 📖 Documentation

- The website, [https://openrosde.org/](https://openrosde.org/), holds the guides, from the quick start to adding a new robot platform.
- The `README.md` and `docs/` of each repository describe what the repository holds.
- The `docs/robot-platforms/<platform>.md` of each platform repository describes its robot, its network, and its launch files.

## ❓ Questions & Problems

- Search the open and closed issues of the repository concerned first.
- Open an issue in the core, [https://github.com/openrosde/openrosde/issues](https://github.com/openrosde/openrosde/issues), for the scripts, the Docker images, the workspaces, or the CI.
- Open an issue in the repository of a platform or a device for its robot or its driver.
- Include the platform name, the host OS, and the output of the failing command.
- Remove any password, token, or secret from what you paste.

## 🔒 Security

Report a vulnerability privately, as [`SECURITY.md`](SECURITY.md) describes, and never in a public issue.
